# PokéWilds v0.8.11 decompiled archive

This repository is an archival reference for a decompilation of the official PokéWilds v0.8.11 `pokewilds.jar`. Download the complete project ZIP from this repository's **Releases** page. GitHub's automatic “Source code” downloads contain only this repository's metadata files.

## Archive contents

- 4,018 Java source files generated with CFR 0.152
- All 62,937 non-class files from the original JAR, under `resources/`
- The original v0.8.11 JAR and the other files from the official `pokewilds-otherplatforms.zip` release, under `release/`
- `verification.json` with source coverage counts and the original JAR hash

Every top-level class in the JAR has a corresponding decompiled source file. The archive passed a full ZIP integrity check, and the extracted resources matched their JAR entries by size and CRC.

This archive was **reconstructed from the official v0.8.11 release**. It is not claimed to be a byte-for-byte copy of an earlier working folder, or to be a buildable replacement for the original project. Decompiled code also contains third-party library code bundled into the JAR.
